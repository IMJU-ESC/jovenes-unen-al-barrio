# Recuperar el acceso de coordinación del IMJU

## Obtener mi enlace privado

Usa la cuenta de Google que administra el proyecto Jóvenes que Unen al Barrio. Pulsa el botón del bloque para copiar el comando a la terminal y presiona Enter. Si Google lo solicita, pulsa **Autorizar**.

```bash
bash administracion/recuperar-coordinacion.sh
```

## Elegir mi contraseña

Abre la dirección privada que mostró Firebase en tu terminal. Elige y guarda tu contraseña. Entra al [portal del programa](https://imju-esc.github.io/jovenes-unen-al-barrio/) con el usuario **coordinacion**. Si aparece «Elige tu contraseña personal», completa ese paso para abrir el panel.
